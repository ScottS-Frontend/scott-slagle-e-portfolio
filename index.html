Built with React, JavaScript, and CSS, deployed on Vercel as part of an advanced frontend internship focused on API integration and e-commerce UI patterns.

  • Summarist

Built with React, JavaScript, CSS, Firebase Auth, and Stripe, deployed on Vercel. An FES Institute bootcamp project focused on full-stack features, authentication flows, and payment processing.

  • Netflix Clone Project

    Html, CSS, Javascript, Next.JS, Firebase Auth, TypeScript

    A Netflix clone built with Next.js featuring Firebase Authentication for user sign-up and sign-in, TMDB API integration for dynamic movie and TV show data, and a responsive browsing UI. Includes protected routes, dynamic content rows, and a randomized hero banner that pulls from live API data with a loading state. Non-functional UI elements are visually disabled with not-allowed cursors to clearly communicate clone scope. Built with Next.js, React, TypeScript, Firebase Auth, Firestore, and TMDB API, deployed on Vercel. An FES Institute bootcamp project focused on API integration, authentication, and async state management.
