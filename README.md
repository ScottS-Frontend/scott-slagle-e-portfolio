## 📋 About

A responsive, portfolio website built to showcase my frontend development projects and skills. Designed for both **potential employers** and **freelance clients**, it features a clean UI, dark mode toggle, functional contact form, and a curated project showcase.

---

## 🛠 Tech Stack

- **HTML5** — Semantic markup and accessibility-focused structure
- **CSS3 / SCSS** — Custom styling with variables, mixins, and responsive breakpoints
- **JavaScript** — DOM manipulation, form validation, and interactive UI
- **GitHub Pages** — Hosting with custom domain (scottslagle.dev)

---

| Feature | Description |

## 🚀 Featured Projects

### 1. Skinstric A.I.
An FES Institute bootcamp paid internship project replicating a modern skincare AI interface. Features a diamond-shaped UI component, multi-step form handling, and API integration for skin analysis results. Built with React, SCSS, and responsive design principles.

**🔗 [Live Demo](https://skinstricai-scottslagle.vercel.app/)**

---

### 2. NFT Marketplace (Ultraverse)
An FES Institute bootcamp project — a fully functional NFT marketplace interface. Features user authentication (Clerk), payment integration with Stripe, and dynamic NFT browsing. Built with React, Next.js, and REST API integration.

**🔗 [Live Demo](https://nftmarketplace-scott.vercel.app/)**

---

### 3. Summarist
An audiobook summary platform with player implementation, library management, and Stripe billing integration. Features skeleton loading states, audio duration handling, and Firestore database integration. Built with React, Next.js, and Firebase.

**🔗 [Live Demo](https://scott-summarist.vercel.app/)**

---

### 4. Netflix Clone
A streaming platform clone featuring TMDB API integration, Firebase authentication, and Firestore database rules. Includes dynamic hero movie randomization, title cards, and responsive UI. Built with React, Next.js, and Firebase.

**🔗 [Live Demo](https://netflix-clone-scott.vercel.app/)**
